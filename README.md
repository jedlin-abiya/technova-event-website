TechNova – Technology Event Website

Overview

TechNova is a responsive technology event website designed to showcase event information, highlights, and a registration page. I built this project to practise my HTML and CSS skills and gain hands-on experience in web development.

Problem Statement

Event information is often scattered across different platforms, making it difficult for participants to find important details in one place. TechNova provides a simple, organised website where visitors can explore event details and access the registration page.

Technologies Used

- HTML5
- CSS3

Features

- Attractive homepage with a hero section.
- Displays technology event details and highlights.
- Separate registration page.
- Navigation between homepage and registration page.
- Custom background images and logo.
- Responsive design for different screen sizes.

Project Structure

- "index.html" – Main homepage of the website.
- "style.css" – Styles the homepage.
- "register.html" – Registration page.
- "register.css" – Styles the registration page.
- "background-front.jpeg" – Homepage background image.
- "register-background.jpeg" – Registration page background image.
- "logotitle.jpeg" – Website logo image.

How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. Navigate through the homepage and registration page.

What I Learned

- Creating webpage structures using HTML.
- Styling webpages using CSS.
- Linking multiple HTML pages.
- Working with images and background properties.
- Designing a multi-page website.
- Uploading and managing projects using GitHub.

Future Improvements
